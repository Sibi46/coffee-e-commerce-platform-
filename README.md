# Kedarmart storefront

Responsive buildless storefront for Kedarkhand Global Ventures. Serve `dist` with any static HTTP server. Routes use URL fragments so every page works on static hosting.

The supplied catalog, company information and contact details are implemented. Search, category browsing, product pages, quantities, cart and wishlist work locally. Cart and wishlist persist in localStorage. Newsletter interest and product enquiries open the visitor's email client.

No real prices, variants, customer reviews, individual brand names, policy terms or payment credentials were supplied. These are explicitly marked pending. Authentication, order creation, payments, account addresses, coupons and tracking require backend services before commercial launch. Illustrative packaging uses CSS; lifestyle imagery is from Unsplash and typography from Google Fonts.

Run `npm test` for JavaScript syntax and static contract verification. No compilation or dependency installation is necessary.
